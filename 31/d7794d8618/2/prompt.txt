### Critical (Must Fix)

1. **[cmd/entire/cli/agent/geminicli/generate.go:14] Gemini `-p ""` passes an empty string as the prompt argument.** The Gemini CLI receives its prompt via stdin (passed to `RunIsolatedTextGeneratorCLI` as the last argument), but it also receives `-p ""` as a command-line argument. 2. **[cmd/entire/cli/agent/copilotcli/generate.go:13] Copilot passes the full prompt as a CLI argument, which will exceed OS argument length limits.** Summarization prompts contain the entire transcript text, which can easily be tens or hundreds of kilobytes. Most OSes have a hard `ARG_MAX` limit (Linux ~2MB, macOS ~256KB). For large transcripts, `exec.CommandContext` will fail with an "argument list too long" error. The Copilot agent should pass the prompt via stdin instead of `-p` if possible, or document this size limitation.
